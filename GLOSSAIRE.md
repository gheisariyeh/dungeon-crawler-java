# Glossaire Java

## `class`

Une classe est un modèle pour créer des objets.

## `object`

Un objet est créé à partir d’une classe.

## `extends`

Le mot-clé `extends` permet à une classe de récupérer les attributs et les méthodes d’une autre classe.

## `abstract`

Le mot-clé `abstract` indique qu’une classe ou une méthode n’est pas complète.

Une classe abstraite ne peut pas être utilisée directement pour créer un objet.

## `super`

Le mot-clé `super` permet d’utiliser le constructeur ou une méthode de la classe parente.

## `@Override`

L’annotation `@Override` indique qu’une méthode de la classe parente est réécrite dans la classe enfant.

## `try`

Le bloc `try` contient le code qui peut provoquer une exception.

## `catch`

Le bloc `catch` récupère et gère une exception.

## `throw`

Le mot-clé `throw` permet de créer et d’envoyer une exception.

## `throws`

Le mot-clé `throws` indique qu’une méthode peut envoyer une exception.

## Javadoc

Javadoc permet d’ajouter des explications sur les classes, les constructeurs, les méthodes et les attributs.

Un commentaire Javadoc commence par `/**` et se termine par `*/`.

## `@param`

La balise `@param` explique un paramètre d’une méthode ou d’un constructeur.

## `@return`

La balise `@return` explique la valeur retournée par une méthode.

Elle n’est pas utilisée pour une méthode `void`.

## `@throws`

La balise `@throws` explique quelle exception peut être envoyée et dans quelle situation.
